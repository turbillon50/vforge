5 · ¿Qué se construye? — DEMO ≠ APP

DEMO — para vender

Súper ágil, puro visual, imposible de romper. Para que el prospecto diga "¿cuánto cuesta?".
  • Sin backend, sin DB, sin auth, sin pagos
  • Datos hardcodeados, navegable, 3 modos
  • Deploy en minutos · calidad visual #1
  • Motor: demo-screens

APP — para construir

El producto real, ya contratado. Auth, DB y pagos de verdad.
  • Next.js + Clerk + Neon + Stripe/MP
  • Integraciones reales por API/MCP
  • Deploy productivo + dominio
  • Motor: demo-pwa-builder / build real
