00 · Regla Crítica

Lo que NUNCA se hace

Estas reglas no tienen excepciones. En ningún entregable, en ningún proyecto.

❌ Prohibido siempre
Lucide React — Solo VFIcons SVG inline de /root/vforge/components/brand/VFIcons.tsx
Colores genéricos — No #000, no #fff, no grays Tailwind, no shadcn. Solo tokens VForge.
shadcn/ui — Todo UI custom con este sistema. Sin librerías de componentes externas.
Placeholders / stock photos — Todo asset con Higgsfield AI. Sin excepciones.
background-clip:text en elemento completo — Solo en span inline. El padre lleva color sólido como fallback iOS.
body::before/after para backgrounds — Usar divs reales con position:fixed. iOS Safari ignora ::before/after en body con scroll.
✓ Siempre así
VFIcons inline SVG · Tokens VForge · UI custom obsidian HUD · Higgsfield para assets · color-scheme:dark en html+body

04 · Background

Grid + Scanlines (fix iOS)

NO usar body::before/after en HTML exportado. iOS Safari los ignora cuando hay scroll nativo. Usar divs reales.

<!-- SIEMPRE estos 2 divs al inicio del body --> <div class="vm-bg-grid"></div> <div class="vm-bg-scan"></div> /* Y en html + body */ html, body { color-scheme: dark; background: #03020a !important; }
/* FIX background-clip:text iOS — el elemento raíz lleva color sólido */ html { color-scheme: dark; background: #03020a; } body { color-scheme: dark; background: #03020a !important; background-color: #03020a !important; }
