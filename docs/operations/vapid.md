# Web Push (VAPID)

Variables en Vercel (proyecto `vforge`):

- `NEXT_PUBLIC_VAPID_PUBLIC_KEY`
- `VAPID_PRIVATE_KEY`
- `VAPID_SUBJECT` (mailto del operador)

Tras cambiarlas, hace falta un nuevo deployment.

Opt-in: banner en `/app` → Activar avisos. Los mensajes del link público y de la sala notifican a owners.
